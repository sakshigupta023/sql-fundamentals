# SQL Fundamentals

This repository contains my MySQL practice and learning exercises performed using MySQL Workbench. It covers fundamental SQL concepts, database creation, table management, CRUD operations, schema modifications, and introductory database projects.

## Topics Covered

### Database Operations

* CREATE DATABASE
* CREATE TABLE
* SHOW TABLES

### CRUD Operations

* INSERT INTO
* SELECT
* UPDATE
* DELETE

### Table Modifications

* ALTER TABLE
* ADD COLUMN
* DROP COLUMN
* DROP TABLE

### Database Project

* SaleOrder Database
* Customer, Employee, Inventory, and Sale Tables
* Primary Keys and Foreign Keys
* Filtering Queries (LIKE, IN, BETWEEN)
* Aggregate Functions (COUNT, SUM, MAX, MIN, AVG)
* GROUP BY Operations

## Tools Used

* SQL
